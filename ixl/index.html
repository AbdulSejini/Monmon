How to work

Every skill, step by step

  1. Open the skill from this page, or type its code (for example B54) in IXL's search box.
  2. New skill? Watch Learn with an example or the video before the first question.
  3. Before answering, put your finger on the key word: the tense (present / past / future), Select all that apply, or first / second.
  4. Wrong answer? Read the whole explanation, say the reason out loud, then press Got it.
  5. When a whole section of IXL's plan is done, press I'm ready for more to open the next skills.
  6. Once a week with a parent: IXL Analytics › Trouble Spots and Questions, to see which mistakes repeat.
  7. First time only: start IXL's Real-Time Diagnostic (Assessment › Step into the arena) so IXL can set the right level in each subject.

Stop rule: 3 wrong answers in a row, or 25 minutes on the same skill → stop, switch to another skill, and come back to it tomorrow.
